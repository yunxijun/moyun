# 墨韵 Design System — 水墨留白·诗意栖居

> 版本 1.0 · 2026-09-21
>
> 本文档是「墨韵」产品的 UI/UX 设计基石。所有页面、组件、动效、文案均应以此为准绳。
> 任何偏离需在本文档中补充说明。

---

## 一、设计哲学

### 1.1 核心理念

**水墨留白 · 诗意栖居**

- **水墨**：取中国书画之形意，以墨色浓淡为视觉主轴，传递东方审美
- **留白**：克制装饰，让内容「呼吸」，以空间感营造意境
- **诗意**：交互不止于功能，每一次点击、滑动都应有诗词般的节奏
- **栖居**：让用户在产品中感到安宁，如同栖于山水之间

### 1.2 设计原则

| 原则 | 释义 | 反面 |
|------|------|------|
| **雅** | 拒绝廉价感；用传统文字替代 emoji，用书法替代图标 | 不要 emoji 堆砌、彩色图标 |
| **简** | 一屏只做一件事，控件最少化 | 不要信息过载、按钮泛滥 |
| **韵** | 动效有节拍，过渡如行书笔势，收放有度 | 不要生硬跳转、无过渡 |
| **静** | 大面积留白，色彩克制，让内容成为主角 | 不要满屏花纹、浓重配色 |
| **意** | 每个元素都有文化出处（印章、信笺、诗签、宣纸） | 不要无意义装饰、西式卡片 |

### 1.3 品牌关键词

`东方` `水墨` `书法` `宣纸` `印章` `竹` `山水` `留白` `文人` `雅致`

## 二、色彩系统

### 2.1 主色板

| 名称 | 色值 | CSS 变量 | 用途 |
|------|------|----------|------|
| 宣纸 Paper | `#faf8f3` | `--paper` | 全局背景色 |
| 墨黑 Ink | `#1a1a2e` | `--ink` | 主文字、重要元素 |
| 朱砂 Vermillion | `#c73e1d` | `--vermillion` | 印章、强调、品牌色 |
| 远山 Mountain | `#5b7f95` | `--mountain` | 次要文字、辅助信息 |
| 鎏金 Gold | `#b8860b` | `--gold` | 标签、会员、特殊标记 |

### 2.2 功能色阶

```
墨黑不透明度系列（基于 --ink）：
  100% — 标题、重要文字
   75% — 正文内容
   55% — 次要内容、预览文字
   35% — 辅助信息、时间戳
   15% — 分割线、边框
    8% — 悬浮背景、卡片底
    4% — 纹理背景、微弱分区
```

### 2.3 禁用色

- 不使用纯黑 `#000000`（过于生硬）
- 不使用纯白 `#ffffff`（仅在卡片内部适当使用，背景必须用宣纸色）
- 不使用高饱和荧光色
- 不使用渐变彩虹色

### 2.4 文字选中色

```css
::selection {
  background: rgba(199, 62, 29, 0.15);
  color: var(--ink);
}
```

## 三、字体系统

### 3.1 字体栈

| 用途 | 字体 | 回退 |
|------|------|------|
| **书法标题** | `Ma Shan Zheng` | `STKaiti`, `KaiTi`, `serif` |
| **草书装饰** | `Liu Jian Mao Cao` | `STKaiti`, `serif` |
| **行书风格** | `Zhi Mang Xing` | `STKaiti`, `serif` |
| **手写随意** | `Long Cang` | `STKaiti`, `serif` |
| **正文 UI** | `PingFang SC` | `Microsoft YaHei`, `-apple-system`, `sans-serif` |

### 3.2 字体加载策略

- 使用 `@fontsource/*` 本地 npm 包，**不依赖** Google Fonts CDN
- 在 `App.vue` 全局引入 `@fontsource/ma-shan-zheng`
- 其他书法字体在结果页按需引入
- Canvas 渲染前调用 `document.fonts.load()` 确保字体就绪

### 3.3 字号规范

| 级别 | 尺寸 (rpx) | 用途 |
|------|-----------|------|
| H1 | 72-96 | 页面主标题（Logo「墨韵」） |
| H2 | 44-52 | 区块标题（「精选」「近作」） |
| H3 | 36 | 卡片标题（诗词标题） |
| Body | 28 | 正文内容 |
| Caption | 24 | 标签文字、诗句 |
| Small | 20-22 | 辅助信息、时间戳、提示 |

## 五、组件规范

### 5.1 印章按钮 (Seal Button)

主操作按钮，用于「落笔成诗」等核心交互。

```
尺寸：180rpx x 180rpx 正方形
边框：朱砂色 5rpx
背景：宣纸 95% 透明
内容：2x2 宫格排列书法字（落笔成诗）
外围：菱形光晕脉冲（旋转45度）
```

- **hover**：微放大 `scale(1.05)` + 微旋转 `rotate(-1deg)`
- **active**：压缩 `scale(0.95)` + 反向旋转
- **loading**：文字变为「挥毫中…」+ 外圈呼吸动画

### 5.2 诗签卡片 (Poem Sign Card)

竖排诗词展示，用于「今日诗签」。

- 微旋转 `rotate(-2deg)` 营造自然感
- 右上角朱砂小印「签」字
- 竖排书法体诗句
- 四角装饰框线
- hover 上浮微旋转

### 5.3 水墨标签 (Ink Tag)

主题选择标签，克制简洁。

- 默认：白底 60% 透明 + 淡墨色边框
- hover：上浮 `translateY(-4rpx)` + 阴影加深
- active（选中）：墨黑填充 + 白色文字 + 墨晕扩散动画
- **文字**：纯中文两字（山水、咏怀、望月…），不带 emoji

### 5.4 折叠卡片 (Ink Card)

用于译文/赏析等可展开内容。

- 收起：淡墨底 + 标题 + `+` 号
- 展开：稍深底色 + 顶部分割线 + 内容淡入下滑
- hover：边框变为远山色

### 5.5 浮动导航 (Side Nav)

固定于屏幕右侧垂直居中。

- 顶部：朱砂印章「墨」字，hover 旋转
- 下方：导航项（笔/鉴/我），书法字方块
- 默认只显示「墨」印章，hover 展开导航项
- 导航项从右侧滑入，有序列延迟
- 当前页高亮：墨底白字

### 5.6 信笺输入 (Letter Paper Input)

- 左侧朱砂竖线（淡渐变）
- 底部横线（极淡墨色）
- 聚焦时：背景变亮 + 边框隐现 + 柔和投影

## 六、布局系统

### 6.1 页面通用结构

```
page 容器
  padding: 0 40rpx
  bottom padding: 200rpx（为浮动导航留空）
  背景：宣纸色 + 纹理叠加
  右侧浮动导航（主页面）
```

### 6.2 结果页布局

- 桌面端（>=768px）：左 55% 右 45% 分栏
  - 左栏：书法卡片预览 + 四角装饰框 + 控制面板（字/纸/式）
  - 右栏：诗题 + 诗句 + 译文/赏析折叠卡片 + 操作按钮
- 窄屏（<768px）：上下堆叠，卡片在上，诗词在下

### 6.3 间距规范

|------|------|------|
| xs | 8rpx | 元素内部间距 |
| sm | 16rpx | 紧凑组件间距 |
| md | 24-32rpx | 标准区块间距 |
| lg | 48-64rpx | 大区块分隔 |

## 七、动效规范

### 7.1 缓动函数

| 名称 | 值 | 用途 |
|------|---|------|
| **标准** | `cubic-bezier(0.4, 0, 0.2, 1)` | 绝大多数过渡 |
| **弹性** | `cubic-bezier(0.22, 1, 0.36, 1)` | 入场动画 |
| **缓出** | `ease-out` | 淡出、收起 |

### 7.2 时长规范

| 类型 | 时长 | 说明 |
|------|------|------|
| 微反馈 | 150-200ms | hover 色变、按压缩放 |
| 标准过渡 | 250-350ms | 展开/收起、切换 |
| 入场动画 | 500-700ms | 页面元素滑入 |
| 氛围动画 | 3-12s | 浮动墨滴、云雾飘动、光晕脉冲 |

### 7.3 核心动画清单

| 动画名 | 用途 | 说明 |
|--------|------|------|
| `fadeUp` | 元素从下方淡入 | opacity 0->1, translateY 24->0 |
| `slideInLeft` | 左栏入场 | 0.7s 弹性 |
| `slideInRight` | 右栏入场 | 0.7s 弹性 |
| `inkFloat` | 浮动墨滴 | 平移+缩放，12s 循环 |
| `mistDrift` | 云雾飘动 | 水平平移，8s 循环 |
| `mountainReveal` | 山峦渐现 | 上移+淡入，2-2.8s |
| `sealHaloPulse` | 印章光晕 | 旋转45度缩放+淡出，4s 循环 |
| `inkSpread` | 标签选中墨晕 | scale 0->2.5 + 淡出 |
| `cardFlash` | 卡片切换过渡 | 白色遮罩闪现 0.45s |
| `inkBounce` | 加载墨滴跳动 | scale 变化，1.4s 循环 |

### 7.4 交互反馈

| 触发 | 反馈 |
|------|------|
| hover 卡片 | 上浮 `translateY(-6rpx)` + 阴影加深 |
| hover 按钮 | 微放大 `scale(1.05)` 或上浮 |
| hover 印章 | 微旋转 `rotate(-2deg)` + 阴影扩散 |
| hover 菜单项 | 缩进 `padding-left +8rpx` + 箭头右移 |
| active 按钮 | 缩小 `scale(0.95)` |
| focus 输入框 | 背景变亮 + 边框隐现 + 柔和投影 |
| 标签选中 | 墨晕扩散后 墨底白字 |

## 九、背景与纹理

### 9.1 全局宣纸纹理

多层叠加：远山色椭圆渐变 + 朱砂色椭圆渐变 + 水平线纹理

### 9.2 水墨山水头部

CSS 实现，三层山峦叠加 + 云雾层：

- 远山：`scaleX(1.6)` 宽幅，浅墨色，最先渐现
- 中山：`scaleX(1.3)` 中等，中等墨色，延迟 0.3s
- 近山：`scaleX(1.1)` 窄幅，深墨色，延迟 0.6s
- 云雾：`radial-gradient` 椭圆 + 水平漂移动画

## 十、文案规范

### 10.1 产品名称

- 中文：**墨韵**
- 英文/域名：**moyun** / **moyun.art**
- 落款：**墨韵AI · moyun.art**

### 10.2 文案风格

- 使用**文言简称**而非现代白话（「以图赋诗」而非「上传图片生成诗」）
- 标签用**两字词**（山水、咏怀、望月、离别、佳节、相思、壮志）
- 控制项用**单字**（字、纸、式）
- 空状态用**文人语气**（「尚无墨痕」而非「暂无数据」）
- 加载状态用**书法意象**（「挥毫中」而非「加载中」）

### 10.3 禁忌

- 不使用「点击这里」「立即体验」等网络营销话术
- 不使用 emoji 作为 UI 元素
- 不使用「哈哈」「666」等网络用语
- 不使用英文按钮文字（Save / Share / Copy）

## 十三、卡片渲染自定义系统

### 13.1 可自定义项

| 维度 | 选项 | 默认值 |
|------|------|--------|
| 字体 | 飘逸行书 / 灵动草书 / 秀丽行书 / 雄浑毛笔 | 飘逸行书 |
| 纸色 | 宣纸米色 / 暖白 / 仿古铜 / 墨色深底 | 宣纸米色 |
| 版式 | 竖版 / 横版 / 方形 / 诗签 | 竖版 |
| 边框 | 无边框 / 素线框 / 双线框 / 四角纹 / 祥云纹 / 竹节纹 | 无边框 |
| 纹理 | 无 / 轻 / 中 / 重 | 中 |
| 字号 | 60% ~ 160% 滑块 | 100% |
| 印章 | 自定义文字（1-4字）+ 四角位置 | 「墨韵」左下 |

### 13.2 控制面板布局

```
┌─────────────────────────────────┐
│ 字  |  纸  |  式               │  循环点击切换
│ 边框 | 纹理 | 字号 ═══●═══     │  边框/纹理点击，字号滑块
├─ 印章区 ────────────── [+] ────┤  可折叠
│  印章文字 [____]               │  1-4字输入
│  位置  [◻ ◻]                  │  2×2 方块选位
│        [◻ ◻]                  │
└─────────────────────────────────┘
```

### 13.3 渲染切换策略

- **不使用 CSS 遮罩动画**，直接重绘 Canvas（清晰快速）
- 监听全部 8 个变量变化，任一变更即触发 `renderCard()`
- 高清导出（2x 分辨率）使用相同参数
