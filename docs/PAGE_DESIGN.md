```
┌──────────────────────────┐

│                          │
│  ┌────────────────────┐  │
│  │                    │  │

│  │   竖排书法渲染      │  │
│  │   宣纸纹理背景      │  │
│  │                    │  │
│  └────────────────────┘  │
│                          │
│  《秋思》· 七言绝句       │  ← 诗词标题
│                          │
│  枫林晚照映长天，         │  ← 诗词文本
│  雁字南归带暮烟。         │
│  独倚西楼人不见，         │
│  一江秋水月如弦。         │
│                          │
│  📖 白话译文              │  ← 折叠展开
│  深秋的枫林在夕阳映照下... │
│                          │
│  🎨 赏析                  │  ← 折叠展开
│  此诗以秋景写离愁...      │
│                          │
│  ── 操作栏 ──            │
│  [换字体] [换背景] [编辑]  │
│  [保存图片]  [分享好友]   │  ← 主操作按钮
│                          │
└──────────────────────────┘
```

### 功能说明
- **换字体**：切换 4 种书法字体风格
- **换背景**：切换宣纸/素色/深色等背景
- **编辑**：微调文字内容
- **保存图片**：Canvas 导出为图片保存到相册
- **分享好友**：生成带小程序码的分享卡片

## 三、卡片设计规范

### 竖排书法卡片（主模板）
```
┌─────────────────────┐
│                     │
│  ╔═══════════════╗  │  宣纸纹理背景
│  ║               ║  │
│  ║  天 映 枫     ║  │  ← 竖排书法文字
│  ║  ，长 林     ║  │     从右到左
│  ║    天 晚     ║  │
│  ║      照     ║  │
│  ║               ║  │
│  ║      [印章]   ║  │  ← 左下角印章
│  ║               ║  │
│  ╚═══════════════╝  │
│                     │
│   《秋思》 墨韵AI    │  ← 底部小字
│                     │
└─────────────────────┘
```

### 设计参数
- 卡片尺寸：1080×1440px（3:4 竖版，适合小红书/朋友圈）
- 宣纸纹理：米色/暖白/古铜色
- 字体颜色：浓墨黑（#1a1a1a）/ 朱砂红（#8b0000）
- 印章颜色：朱红（#cc3333）
- 边距：上下左右各 120px

## 六、视觉风格

### 色彩体系
| 用途 | 颜色 | 色值 |
|---|---|---|
| 主色（墨色） | 浓墨黑 | #1a1a1a |
| 辅助色（朱砂） | 印章红 | #cc3333 |
| 背景色 | 宣纸米 | #f5f0e8 |
| 次背景 | 淡墨灰 | #e8e0d4 |
| 文字色 | 墨黑 | #333333 |
| 次文字 | 淡墨 | #888888 |
| 强调色 | 金色 | #c0a060 |

### 设计原则
1. **东方极简**：大量留白，水墨质感
2. **纸质温度**：宣纸纹理、毛笔笔触
3. **克制典雅**：避免花哨装饰，让诗词和书法成为主角
4. **现代融合**：传统审美 + 现代UI交互
