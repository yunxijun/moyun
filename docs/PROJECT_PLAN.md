# 墨韵（MoYun）— AI 诗词书法卡片生成器

## 项目愿景

> 输入心情/场景/主题 → AI 作诗 → AI 书法渲染 → 输出一张精美的「诗词书法卡片」

将 AI 诗词生成与书法视觉呈现融合为一体化文化体验产品，同步运营自媒体矩阵实现飞轮增长。

---

## 一、产品定义

### 核心功能
1. **AI 作诗**：输入关键词/心情/场景，生成格律正确的古体诗词
2. **📷 图片作诗**：上传 1-3 张照片 + 可选文字，AI 分析画面意境后作诗（多模态 VLM）
3. **书法渲染**：将诗词以毛笔书法风格渲染为精美视觉卡片
4. **🖌️ 真实书法家风格**：支持选择王羲之/颜真卿/欧阳询/宋徽宗等书法家的笔迹风格（UniCalli）
5. **卡片排版**：竖排文字 + 宣纸纹理 + 印章 + 落款，输出传统书法作品效果
6. **社交分享**：一键分享到朋友圈/微信好友，带小程序码裂变传播

### 扩展功能（后期）
- 多书体切换（楷书/行书/草书/隶书/瘦金体）
- 藏头诗、对联、词牌生成
- 自定义印章
- 节日主题模板（春节对联、中秋诗词、生日祝福）
- 照片 + 书法诗词合成（用户照片作为卡片背景）
- 自定义书法风格学习（上传书法样本，AI 学习风格）
- 实物文创下单（装裱画/卷轴/明信片）

### 目标用户
- 文化爱好者（诗词/书法/国学）
- 社交需求用户（节日祝福/朋友圈分享）
- 自媒体创作者（需要文化类素材）
- 送礼场景（个性化文创礼品）

### 技术选型

| 层级 | 选型 | 理由 |
|---|---|---|
| **跨端框架** | uni-app (Vue3 + Vite + TypeScript) | 一套代码 → 小程序 + H5 + iOS + Android |
| **官网** | Nuxt 3 (SSR/SSG) | SEO 友好、落地页、博客、内容营销 |
| **桌面端** | Tauri（包装 H5 产物） | 安装包小（几MB）、系统级能力、适合你的C++背景 |
| **统一后端** | Vercel Edge Functions / Hono.js | 全球 CDN、免运维、TypeScript |
| **AI 诗词** | DeepSeek API（多模态） | 支持文字+图片输入，全端通用 |
| **书法渲染 MVP** | Google Fonts 开源书法字体 + Canvas | 快速可靠，无 GPU 依赖 |
| **书法渲染 V2** | UniCalli（云 GPU 部署） | 真实书法家风格（王羲之/颜真卿等） |
| **排版** | Canvas 2D API | 竖排文字、纹理叠加、印章合成 |
| **数据库** | Supabase / PlanetScale | 用户、作品、付费记录 |
| **对象存储** | Cloudflare R2 / 阿里 OSS | 生成的书法卡片图存储 |
| **付费** | 微信支付 + 支付宝 + Stripe（海外） | 多端多渠道覆盖 |

### 书法字体方案（MVP）

使用 Google Fonts 开源中文书法字体（SIL OFL 许可，可商用）：

| 字体 | 风格 | 适合场景 |
|---|---|---|
| Ma Shan Zheng (马善政) | 飘逸行书 | 通用诗词 |
| Liu Jian Mao Cao (柳建毛草) | 灵动草书 | 豪放派词 |
| Zhi Mang Xing (志莽行) | 秀丽行书 | 婉约派词 |
| Long Cang (龙藏) | 雄浑毛笔 | 对联/匾额 |

### 图片作诗方案（多模态 VLM）

微信云开发已支持多模态大模型直接调用：
- DeepSeek-V4 / 混元 / Kimi-K2.6 / GLM-5.1
- 支持图片 + 文字混合输入
- 小程序端 `wx.cloud.extend.AI` 直接调用，零后端

流程：用户上传照片 → VLM 分析场景/意象/情绪 → 输出场景描述 → 诗词 LLM 据此作诗

### 书法渲染 V2 方案：UniCalli（真实书法家风格）

[UniCalli](https://github.com/EnVision-Research/UniCalli)：
- 基于 FLUX 扩散模型的整列书法生成框架
- **支持书法家**：王羲之、颜真卿、欧阳询、赵佶（瘦金体）、黄庭坚等
- **支持书体**：楷书、行书、草书
- **输入**：文字（5字） + 书体 + 书法家 → 输出列级书法图
- **显存需求**：~23GB（4-bit 量化约 18GB）
- **部署方式**：云 GPU（如 AutoDL / 算家云 A100）

### 书法渲染 V3 方案：FontDiffuser（自定义风格学习）

[FontDiffuser](https://github.com/...)（AAAI 2024）：
- One-Shot 能力：一张参考图即可生成新字
- 可用于：用户上传自己喜欢的书法样本 → AI 学习 → 生成任意文字
- 终极形态：每个人都能拥有自己的 AI 书法家

### 其他参考方案

| 方案 | 说明 |
|---|---|
| Calligrapher (fal.ai) | 蚂蚁+港科大开源，API 可用，主要支持英文 |
| zi2zi-chain | GAN 路线，有颜真卿/柳公权/赵孟頫预训练模型 |
| CalliFormer | 2025 论文，35 位书法家，结构感知 Transformer |
| Moyun（论文同名） | Vision Mamba + TripleLabel，190 万数据集 |

## 六、风险与应对

| 风险 | 应对 |
|---|---|
| AI 生成诗词格律不准 | 加格律校验层，System Prompt 强约束 |
| 书法字体效果不够惊艳 | MVP 先跑通链路，后期升级 AI 书法 |

| 自媒体起号慢 | 坚持日更，用产品生成内容降低制作成本 |
| 付费转化率低 | 先验证免费用户量，后调整付费策略 |
